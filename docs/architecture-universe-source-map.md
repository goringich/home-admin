# Architecture Universe source ownership

Project Atlas renders architecture but does not own the system architecture facts.

| Concern | Authority/source |
| --- | --- |
| Critical layers and authorities | `goringich/__home_organized` Architecture v2 contracts |
| Technology inventory | `technology-census.json` |
| Satellite/legacy inventory | `satellite-systems-census.json` |
| GitHub repository universe | `owner-repository-census-v1.json` |
| Product membership | `product-registry.json` |
| Project ownership/exclusions | `project-scope-boundaries.json` |
| Fresh local project state | Atlas `snapshot.json` |
| Fresh machine observations | bounded live census |
| Human visualization | Project Atlas `#/architecture` |

Atlas may compose and visualize these inputs. It must not silently redefine their ownership or turn source presence into a live-health claim.
